酒店打印助手

适用场景：
1. Windows 台式机常开。
2. 台式机本地连接 Epson 610K 针式打印机和 HP 激光打印机。
3. 酒店订单在 VPS 网站上录入、修改、发送打印。

日常使用：
1. 双击“启动酒店打印助手.bat”。
2. 保持窗口打开。
3. 在 VPS 网站销售订单页面点“发销售单打印”或“发采购单打印”。
4. 工具会自动接收、下载、切换打印机并打印。
5. 早上开工前点“立即检测”，确认服务器、Epson、HP 都是绿色就绪。

如果 Windows 不让打开：
方法一：
1. 右键下载的 zip 压缩包，点“属性”。
2. 勾选“解除锁定”，点“确定”。
3. 再解压，然后双击“启动酒店打印助手.bat”。

方法二：
1. 如果已经解压，先双击“首次解除安全限制.bat”。
2. 再双击“启动酒店打印助手.bat”。

第一次设置：
1. 打开“打印助手配置.json”。
2. serverUrl 默认是 http://服务器IP，域名稳定后可改成域名。
3. salesPrinter 填 Windows 里 Epson 针式打印机的完整名称。
4. purchasePrinter 填 Windows 里 HP 激光打印机的完整名称。
5. token 不要随便发给别人。

打印规则：
1. 销售单默认发到 Epson 610K，二等分纸 241mm x 140mm。
2. 采购单默认发到 HP 激光打印机，A4 打印。
3. 如果销售单要三等分，后续可在网站按钮上扩展选择。

检测功能：
1. “立即检测”会检查服务器连接、销售单打印机、采购单打印机。
2. “测试销售单”会向 Epson 打一张测试销售单。
3. “测试采购单”会向 HP 打一张测试采购单。
4. 如果显示脱机、暂停、缺纸、错误，请先处理打印机状态再正式打印。

注意：
1. 台式机不用对外开放端口，只要能访问 VPS。
2. 工具没打开时，服务器里的打印任务不会丢；下次打开会继续接收。
3. 第一次打印前，建议在 Windows 打印机首选项里保存好 Epson 连续纸规格和进纸方式。
